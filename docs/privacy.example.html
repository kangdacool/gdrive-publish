Privacy policy

gdrive-publish (personal installation) · last updated YYYY-MM-DD

Who uses it

This is a personal tool used only by its owner, with the owner's own Google account, on the owner's own computer.

What it can access

  • Google Drive (drive.file): only files and folders the tool itself created.
  • Google Sheets (spreadsheets): only to write a link into a cell the owner chooses.

What it does with the data

  • Files go from the owner's computer to the owner's Drive and nowhere else.
  • Uploaded files are shared as “anyone with the link can view”. Edit access is never granted.
  • The sign-in token is stored only on the owner's computer.
  • No data is sent to any third party, sold, logged remotely or used for advertising.

Removing access

Revoke access at any time at myaccount.google.com/permissions.
